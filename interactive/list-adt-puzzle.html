List ADT Sequence Puzzles

Transform a sequence using remove(index) and insertBefore(index, value). Plan the operations, observe their effect on order, and try another solution. No storage representation is assumed.

Target sequence

Current sequence

Explain the operation

Indices start at 0. Removing an element closes its position in the sequence. The insertion index refers to the shorter sequence after removal; inserting at its size appends. A single prepared move has two observable ADT operations.

Try solving a puzzle in fewer moves. Would the abstract sequence result change if the List ADT used a different implementation?
