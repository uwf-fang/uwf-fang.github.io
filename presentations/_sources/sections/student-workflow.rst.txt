Use Class Time as Your Primary Workspace
----------------------------------------
+ During the first weeks, actively follow the live walkthroughs for the course
  setup, Canvas layout, Git, Classroom 50, labs, and projects.
+ Take notes and ask questions as soon as a step is unclear. Reconstructing a
  missed technical workflow later is usually slower and more stressful.
+ Flexible attendance does not change your responsibility to learn workflows
  demonstrated in class. Later assignments build on these skills.
+ Before asking for help:

  #. Read the lab or project instructions and locate the relevant Canvas module.
  #. Review the class Zoom recording if you missed or need to repeat a
     demonstration.
  #. Reproduce the problem and copy the exact command and error message.
  #. Push your current code before requesting help with a programming problem.
