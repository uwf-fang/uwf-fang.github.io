Binary Heap: Tree & Array

Explore an existing heap or build one operation at a time. During insertion, watch the new value enter at the array tail and percolate up. During removal, watch the root leave, the tail move to the root, and that value percolate down. The tree and array views stay synchronized at every step.

Set up

Choose an operation

Step through

Begin prepares an operation. Step performs one append, comparison, swap, or removal action. Clear heap removes all values; Generate random heap starts a new example.
