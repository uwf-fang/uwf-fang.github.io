Grow with your AI agent skills

How feedback on a draft, a slide, or a workflow can grow into a reusable AI agent skill.

November 11, 2026

When I started drafting posts for this blog with an AI assistant, I asked for something short and casual. Reading the first drafts, I found myself wanting another paragraph or two in places. A good example deserves enough room to make sense, and a link to the official reference gives a curious reader somewhere to go next.

That’s the kind of thing I’d put in an agent skill, a set of instructions an AI assistant can reuse for a particular kind of work. The writing skill for these posts can capture what I mean by “casual” and which details deserve room. The next time I write a post, I can start with those preferences and see how they hold up on a different topic.

I can see the same thing happening with visuals. After making a few slide decks, I might notice that I keep asking for larger labels on diagrams or for the same colors to mean the same things across slides. A visual style skill can capture those choices and point to a couple of slides that show what I mean. A separate skill might capture a whole routine, like turning rough notes into an outline, a draft, and then a set of slides.

The tools can help write the skill itself. Codex has a built-in $skill-creator, and Claude Code has an installable Skill Creator plugin from Anthropic. A conversation where you worked through a few revisions gives either tool something concrete to distill. I’d want to read the result and decide which preferences are worth carrying into the next project. OpenAI’s guide to creating skills · Anthropic’s Skill Creator plugin

What I like about this is how much I learn about my own work in the process. I often know when a draft feels off before I can explain why. Putting the reason into words helps me make the same judgment the next time, even if I’m working on my own.
