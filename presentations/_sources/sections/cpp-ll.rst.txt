******************
Linked-List in C++
******************

.. container:: subtitle

  |author|

Overview
========
+ A linked data structure
+ Models a sequential collection of elements
+ Linked nodes (class/struct) are connected by links (C++ pointers)
+ Logically contiguous, but not physically contiguous
+ Advantages

  * Dynamic size
  * Efficient insertion and removal
  * Not requiring contiguous memory
  * Sequential access

+ Limitations

  * Inefficient random access
  * Extra memory space for links

Linked-List Variations
======================
+ Minimal implementation: a head pointer; singly-linked
+ Ideal implementation: a head pointer, a tail pointer, and a size;
  doubly-linked
+ Instance variables

  * head pointer
  * tail pointer (optional)
  * size (optional)

+ Number of links per node

  * singly-linked - a pointer to next node
  * doubly-linked - pointers to previous and next nodes

+ Other variations (FYI)

  + Circular linked list
  + Dummy node before the first node

Operations and Time Complexity
==============================
+ ``Based on the ideal implementation``
+ Access

  * by index :math:`\Theta(n)`
  * first :math:`\Theta(1)`
  * last :math:`\Theta(1)`

+ Insertion/removal

  * at the beginning :math:`\Theta(1)`
  * at the end :math:`\Theta(1)`
  * at a specified position (by pointer/iterator) :math:`\Theta(1)`
  * at a specified position (by index) :math:`\Theta(n)`

C++ Implementation Details
==========================
+ Linked list class

  * head pointer
  * tail pointer (optional)
  * size (optional)

+ Linked node class/struct

  * top-level or nested

+ Use class templates for generalization

  * type of data stored in nodes can be parameterized
