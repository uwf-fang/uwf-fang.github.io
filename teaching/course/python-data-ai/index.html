Python Foundations for Data Science and AI

This course is in development and is planned for next year. Its working title is Python Foundations for Data Science and AI. The course number, credit designation, format, and software platform have not been finalized.

Course purpose

Python is the subject of the course. Data science and artificial intelligence provide motivating examples and context for learning the language. The course is intended to prepare students for later study in data science, machine learning, deep learning, and large language models; it is not a data-science or computer-science programming-sequence course.

Intended audience

The proposal is aimed at students across science, engineering, health, business, social science, geography, information systems, and other fields. No prior programming experience is expected. The course is not intended to replace CS1 or a computer-science programming sequence, or to provide advanced software-engineering training.

Planned scope

The current proposal emphasizes Python fundamentals: syntax, control flow, functions, collections, files, exceptions, modules, simple packages, notebooks, and debugging. Students would practice reading, modifying, organizing, and explaining code through a small number of accessible applied examples. The proposed 7-week version is intended to stay focused and low workload.

The proposal also includes a brief introduction to NumPy, pandas, and Matplotlib as examples of the Python ecosystem. Machine-learning theory, neural-network training, and LLM implementation are outside the planned scope. AI-assisted coding may be treated as a tool that students must check, document, and use accountably.

Catalog-description draft

This course introduces Python programming through practical computational problems and prepares students for later coursework in data science, machine learning, deep learning, and artificial intelligence. Students apply core Python syntax, control flow, functions, collections, files, exceptions, modules, simple packages, notebooks, and debugging practices. The course briefly introduces NumPy, pandas, and Matplotlib as examples of the Python ecosystem. No prior programming experience is required.

Planning details to be confirmed

  • Course prefix and number
  • Final credit designation and course length. The primary proposal is 1.5 credits over 7 weeks; a 3-credit, 14- or 15-week format is a backup option.
  • Whether junior or sophomore standing is recommended
  • Whether the course may count toward a university-wide elective
  • Local software and notebook platform
