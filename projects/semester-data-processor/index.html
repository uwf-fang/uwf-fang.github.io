Semester Data Processor

Combine course data and produce reports for learning-outcome assessment.

Semester Data Processor is a Python command-line tool for faculty and course coordinators who work with course rosters, Canvas gradebook exports, and learning-outcome assessments. It combines data from multiple sections and produces reports from a configurable assessment plan.

The workflow merges section rosters, associates gradebook records with roster attributes, and evaluates selected assignments against specified thresholds. Assessment items can target particular majors and retain their own student populations and reporting totals.

Outputs include combined roster and gradebook CSVs, detailed and summary assessment tables, an academic-year Excel workbook, a Markdown assessment report, and a generated dataset README with a processing log. The source inputs remain available for comparison with the generated results.

From an installed checkout, the full workflow runs with

semester-processor run-all /path/to/course-directory

The repository documents the expected input files, assessment-plan format, individual processing commands, and spreadsheet reporting options. Python 3.10 or newer is required. The project uses the MIT license. Source, installation, and usage · MIT license
