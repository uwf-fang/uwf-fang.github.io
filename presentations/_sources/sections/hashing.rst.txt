Overview
========
Use our `Hash Table Collision & Load Factor Lab </interactive/hash-table-lab.html>`_ to compare separate chaining and linear probing, then watch the table resize.

+ Broad definition: Hashing is a process of mapping keys of a certain type to
  data of another type.
+ Other definition: Hashing is a process of mapping data of arbitrary size to
  data of fixed size. (not always true)
+ Hash function

  * The core of hashing

+ Representation: ``<start type> -> <destination type>``

  * ``<start type>``: The type of data to be hashed, sometimes called key type
  * ``<destination type>``: The type of data after hashing, sometimes called
    hash value type or hash code type
  * E.g. ``int -> int``, ``int -> string``, ``string -> int``, ``string ->
    string``

Hashing Glossary
----------------
.. glossary::

  Hash Function
    A function that maps a variable sized value to a fixed sized value.

  Key (hashing)
    The input value to the hash function.

  Value (hashing)
    A.k.a hash value, hash code or simply hash. The output of the hash
    function.

  Key space / Domain (hashing)
    The set of all possible keys.

  Value space / Range (hashing)
    The set of all possible values.

  Collision (hashing)
    Multiple distinct keys maps to a same output value.

Hash Function
=============
+ The function that performs the mapping
+ Required properties

  * deterministic
  * uniform distribution

    - hash function that maps all possible input values (keys) with roughly
      equal probability to each possible output value (hash code)
    - ensures minimal collision
    - hard to guarantee and prove

+ Other properties (application specific)

  * variable length key to fixed length hash value
  * constant time computation :math:`\Theta(1)`
  * squeeze a large domain to a smaller range
  * chance of collision
  * asymmetric

Design of Hash Functions
------------------------
+ Integer keys
+ String keys

  * Handle variable length
  * All characters are involved
  * Uniform distribution

+ Asymmetric hash functions

  * Hard to reverse
  * Cryptographic hash functions
  * E.g. MD5, SHA-1, SHA-2, SHA-3

Applications
============
+ Hash table data structure

  * Hash Map (Map ADT, dictionary, key-value store)
  * Hash Set (Set ADT)

+ Fingerprinting

  * Short summary of a large data set
  * Checksum
  * Password management

+ Cryptography
+ Advanced data structures

  * Bloom filter
  * Cuckoo filter
  * Merkle tree (e.g. BitCoin)
