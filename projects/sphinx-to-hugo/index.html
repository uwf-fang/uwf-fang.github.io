Sphinx to Hugo

A migration tool for teaching materials, with conversion results you can inspect.

The local prototype uses Sphinx to resolve documents and an adapter to export Hugo-oriented Markdown. It handles course navigation, code, math, diagrams, and linked resources while recording migration findings.

The tool currently lives in a separate local repository in this workspace. A public repository link can be added when it is published.
