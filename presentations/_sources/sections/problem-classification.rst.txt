Problem Classification
**********************
.. container:: subtitle

  |author|

Overview
========
+ Essential to understand the problem
+ Most problems can be solved by multiple algorithms
+ Many problems can be solved by similar algorithms
+ Essential to choose or design the algorithms to solve the problem

By The Goal
===========
+ Find one solution that satisfies the requirements - search
+ Find all solutions that satisfy the requirements - enumeration
+ Find the best solution according to an objective - optimization
+ Determine whether at least one qualifying solution exists (yes/no) - decision
+ Count the qualifying solutions - counting
+ Find the output of a mathematical or logical function - evaluation problem

These labels describe the requested output, not the algorithm used. A problem
may have several related formulations. Enumerating all solutions can be used
to find one, decide whether any exist, count them, or select the best one, but
an algorithm may solve those goals directly without enumerating every
solution. Search asks for a witness; decision asks only whether a witness
exists.
