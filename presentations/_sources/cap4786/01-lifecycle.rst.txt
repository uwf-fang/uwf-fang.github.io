Big Data Lifecycle
------------------
+ Many definitions out there
+ Obscure definitions 🤔
+ Tried to make a definition for this course

  * three stages - sequential and ordered steps
  * three aspects - optionally involved in multiple stages

Stages
------
Stages in a data flow pipeline. Downstream stages rely on data generated in
upstream stages. These stages are frequently iterative, which means people may
go back to early stages whenever changes happens in later stages require
adjustment in early stages.

1. Data acquisition

   - collect data from various sources

2. Data processing

   - convert raw data to a form that is ready for downstream analysis

3. Data analysis

   * Not only traditional statistical analysis
   * Various outcomes

     - reports and dashboards
     - visualizations
     - statistical or machine learning/deep learning model
     - optimized procedure/algorithm

Aspects
-------
Things that must be considered in many stages in the data flow pipeline. As
data are generated after every stage or sub-stages, these aspects need to be
considered on any new data.

+ 💽Data storage

  Every stage may generate data to be stored in the data storage layer.

+ 🔐Data security and privacy

  Whenever data are collected or generated, this aspect must be considered.
  Sometimes need to comply to regulations.

+ ✅Data governance and management

  Quality control of data and process. Communications with stakeholders.
