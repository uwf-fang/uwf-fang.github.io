Amortized Analysis
==================
+ Motivation: To analyze the average time complexity of a sequence of
  operations performed on a data structure.
+ When best, worst, and average cases are not enough to describe the
  performance of an algorithm or a data structure.
+ Types of amortized analysis:

  * Aggregate analysis
  * Accounting method
  * Potential method

+ Example of dynamic data structures that require amortized analysis:

  * Dynamic arrays (resizing)
  * Hash tables (rehashing)
  * Self-balancing binary search trees (balancing)
  * Splay trees (splaying)
