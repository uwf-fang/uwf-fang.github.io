01. Computational Foundations & Problem Solving

Problem Types & Algorithmic Paradigms Interactive Lesson

Explains the universal two-stage problem pipeline connecting Enumeration to Search, Decision, Counting, and Optimization. Features an interactive 0/1 Knapsack sandbox and combinatorial explosion analysis.

  • Interactive Sandbox: 4-item Knapsack (Weight ≤ 5 kg) evaluated across 5 problem types.
  • Combinatorial Analysis: Why enumeration fails for large inputs ($2^{50} \approx 10^{15}$).

03. Graph Algorithms & Shortest Paths

Single-Source Dijkstra's Algorithm Canvas Graph Visualizer

Interactive shortest-path tree construction on a weighted graph. Features arbitrary source vertex selection, synchronized Priority Queue relaxation, step-by-step state tracking, and click-to-trace shortest path.

  • Priority Queue Dynamics: Synchronized PQ table updates after each edge relaxation.
  • Crisp Canvas Rendering: High-DPI line art with node status states (Unvisited, Evaluating, Visited).
  • Shortest Path Tree: Edge highlighting and click-to-trace shortest route from the source.
