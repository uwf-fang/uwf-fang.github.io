Stack Abstract Data Type
========================
+ Overview
+ Behaviors

Overview
--------
+ A stack ADT is a container of elements that are inserted and removed according
  to the last-in first-out (LIFO) principle.
+ A.k.a. Push-down list, LIFO list, etc.
+ Characteristics

  * Homogeneous
  * Access order is LIFO/FILO
  * Finite
  * Dynamic size

+ Applications

  * Memory management (function call)
  * Editing tools (undo/redo)
  * Backtracking algorithms
  * Expression evaluation and conversion

+ Known as one of the linear ADT because it is usually implemented using a
  linear data structure. It is not logically linear. The concept of ``top``,
  ``bottom``, ``depth`` are also based on the implementations but not relevant
  to the ADT itself.

Behaviors
---------
+ push: Insert an element to the stack.
+ pop: Remove and return an element from the stack.
+ peek: Return the element to be popped from the stack.
+ isEmpty: Check if the stack is empty.
+ size (optional): Return the number of elements in the container.
