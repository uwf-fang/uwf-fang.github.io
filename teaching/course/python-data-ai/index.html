Python Foundations for Data Science and AI

Textbook and slide companion

Use these outlines and selected explanations alongside the required Python for Everybody textbook and classroom slides. Short topic pages organize the material and provide supporting resources; they do not repeat every detail taught in class.

How to use these materials →

Course Description

Learn Python programming through small, practical problems with examples from data science and artificial intelligence. You will build a foundation for later study in data science, machine learning, and AI while learning to read, write, modify, debug, and explain Python code.

Prerequisites

No prior programming experience is required. Students from all majors are welcome.

Course Topics

  • Python syntax, variables, expressions, conditionals, and loops
  • Functions, strings, and collections
  • Files, exceptions, and debugging
  • Notebooks, modules, and simple packages
  • A brief introduction to NumPy, pandas, and Matplotlib for working with data

Required Textbook

Python for Everybody: Exploring Data in Python 3, by Charles R. Severance.

The required textbook is free. Read or download Python for Everybody.
