C++ Implementation of Stack ADT
===============================
Try stack operations in our `ADT Explorer </interactive/adt-overview/index.html>`_ before implementing the interface in C++.

+ Use C++ STL container as a stack: std::stack, std::vector, std::deque,
  std::list
+ Make from scratch as templates
+ Example public interface:

  .. code-block:: cpp

    template <typename T>
    class Stack {
     private:
      ///...
     public:
      void push(const T& value);
      T pop();
      T top() const; // or peek()
      bool isEmpty() const;
    };

Data Structures
---------------
List of data structures and STL containers that can be used to implement a
stack.

+ Partially filled C array

  * push pop at the end
  * fixed capacity

+ Linked list

  * Ideal
  * singly, add and remove at the head
  * doubly, add and remove at the head or tail

+ Make a wrapper class using other STL containers

  * std::vector
  * std::deque
  * std::list
