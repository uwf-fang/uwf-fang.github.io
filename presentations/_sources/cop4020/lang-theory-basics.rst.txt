============================
+ Part of theoretical computer science (Theory of Computation Course)
+ Studies formal languages and automata

  * Automata are abstract machines that recognize languages.

+ Automata theory: abstract machines modeling computation

Core Concepts in Theory of Computation
--------------------------------------
* Formal languages: mathematical models of programming languages
* Automata theory: abstract machines modeling computation
* Computability: what problems can/cannot be solved algorithmically
* Complexity theory: resource requirements for solving problems

Formal Languages
----------------
+ Mathematical system to describe syntax and semantics of languages.

  * Alphabet: finite set of symbols (Σ)
  * String: finite sequence of symbols from alphabet
  * Language: set of strings following specific rules
  * Grammar: rules for generating valid strings

Symbolic Notation in Formal Languages
-------------------------------------
- Terminal (a, b, ...): single character in the alphabet, cannot be expanded
- Nonterminal (A, B, ...): can be expanded
- Terminal or nonterminal (X, Y, ...):
- Strings of terminal (w, x, ...): sequence of terminal symbols
- Mixed strings :math:`\alpha, \beta, \gamma, ...`: sequence of terminal and
  nonterminal symbols

.. note::

   BNF (Backus-Naur Form) and its variations are a widely used notation to
   describe formal grammars in the context of programming languages and
   compilers.

Automata Types
--------------
* Finite automata: Deterministic and non-deterministic Finite Automata (DFA,
  NFA)
* Pushdown automata: stack memory
* Linear-bounded automata: limited tape memory
* Turing machines: infinite tape memory

Chomsky Hierarchy
-----------------
+ Developed by Noam Chomsky in 1956
+ Automaton works as recognizer for language.
+ Classifies formal grammars and automata into four nested levels

   :header: "Type", "Grammar", "Automaton", "Language Example"

   "Type 1", "Context-sensitive", "Linear-bounded automaton (LBA)", "Most languages"
   "Type 2", "Context-free", "Pushdown automaton (PDA)", "Expression grammar"
   "Type 3", "Regular", "Finite automaton (FA)", "Regular expressions, Lexemes"
