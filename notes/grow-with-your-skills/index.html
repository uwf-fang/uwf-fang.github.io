Grow with your AI agent skills

How working through a batch of documents can help you build a better AI agent skill for the next batch.

November 11, 2026

Suppose I have a year’s worth of electricity bills and want to see how my usage changed. I could ask an AI assistant to pull the billing dates, electricity use, and current charges into a table. The first few rows might look fine. Then one month shows an unusually high charge, and I realize the assistant copied the amount due, which includes a balance from the previous month.

That distinction is worth saving in an agent skill, a set of instructions an AI assistant can reuse for a particular kind of work. For the next batch, I’d tell it which line on the bill to use for current charges and ask it to flag values it can’t locate. It could also put dates in a consistent format, keep a reference to the source page for each row, and leave names, addresses, and account numbers out of the table.

Once I start comparing the rows, I might notice something else. One bill covers 27 days and another covers 34, so a jump in total usage may just reflect a longer billing period. I can add a column for average use per day and see whether that makes the comparison more useful. Working with the results tells me what I want the skill to do differently next time.

The tools can help write the skill itself. Codex has a built-in $skill-creator, and Claude Code has an installable Skill Creator plugin from Anthropic. I can give either tool the instructions that worked and a couple of examples that tripped me up, then review which rules it carries forward. OpenAI’s guide to creating skills · Anthropic’s Skill Creator plugin

What I like about this is that I’m learning alongside the assistant. The next time I look at a bill, I know why the number at the top and the number I need can be different. I’d want to remember that even if I were doing the work by hand.
