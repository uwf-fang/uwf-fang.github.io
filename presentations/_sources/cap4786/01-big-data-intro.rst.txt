What is Big Data
================
+ Definition

  Big Data is a term that refers to datasets that are so large and complex that
  traditional data processing tools and methods are no longer sufficient to
  handle them. In other words, Big Data is characterized by its size,
  complexity, and speed of creation.

+ Characteristics: Value, Volume, Velocity, Variety, Veracity
+ Big data in various domains
+ Big data compared to traditional data

Application Domains
-------------------
+ Social media: Facebook, Twitter, etc.
+ Content provider: Netflix, Youtube, etc.
+ Health care: IBM Watson Health, CDC, etc.
+ Finance: Goldman Sachs, American Express, etc.
+ Retail: Amazon, Walmart, etc.
+ More domains: ChatBot, Internet of things (IOT), Sensor network, etc.

Characteristics & Challenges
============================
+ 💵 Value: high-level insights, knowledge

  * Report, Chart, Model, Opinion

+ 📈 Volume: terabytes to petabytes, and even beyond.

  * 175 zettabytes (:math:`10^{21}`) by 2025

+ 🚀 Velocity: high speed, in real-time or near real-time

  * “53 Important Statistics About How Much Data Is Created Every Day”

+ 🗂️ Variety: structured, unstructured, and semi-structured
+ ✅ Veracity: a concern on missing or inconsistent data

  * costs 3 trillion GDP in US
  * not relevant when data is clean and complete

Challenges
----------
+ Data Quality - Veracity, Low quality data exists
+ Discovery - Variety, Volume, Collection of large dataset from heterogeneous
  sources
+ Storage - Volume, Cloud/Parallel storage
+ Analytics - Veracity, Volume, Value
+ Security - Velocity, Volume, Variety
+ Lack of Talent

Frameworks
----------
+ Many tools are built around frameworks
+ Two state-of-art Frameworks: Hadoop and Spark
+ Apache Hadoop - an ecosystem

  * Core components: HDFS and YARN
  * Many other tools: Hive, Pig, Sqoop, Flume, etc.

+ Apache Spark - an all-around tool

  * core
  * Spark-SQL
  * Spark streaming
  * MLlib
  * GraphX
