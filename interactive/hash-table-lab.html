Hash Table Collision & Load Factor Lab

Follow one bucket access or probe at a time. Compare chaining with linear probing, then search, remove, and watch keys move during resizing.

Insertion or operation trace

Bucket / slotContents

Hashing in familiar notation

h(key) = key % capacity

probe(i) = (h(key) + i) % capacity

For capacity 7: 16 % 7 = 2. Linear probing checks 2, 3, 4, … and wraps around. For negative keys, compute the remainder once and add capacity if it is negative.

This is a Set ADT: inserting an existing key leaves it unchanged. Load factor is the number of live keys divided by capacity. † is a deleted slot; it does not end a search. Rehashing removes tombstones.

Counts distinguish bucket/slot reads, key comparisons, and rehash moves. In chaining, one bucket read can be followed by several key comparisons.
