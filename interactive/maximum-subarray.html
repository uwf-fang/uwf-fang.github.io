Maximum Subarray Comparison Lab

Find a nonempty contiguous subarray with maximum sum using incremental brute force, divide and conquer, or Kadane’s algorithm. Inspect candidate intervals, recursive calls, and running sums. All three use the same tie rule: earliest start, then earliest end.

Apply array after editing. Changing the algorithm replays the same array. One Step is an addition, call/split, return, or result decision—not a fixed amount of CPU time.

Reading the three approaches

  • Brute force: choose each start index and extend a running sum through every possible end.
  • Divide and conquer: solve the left and right halves, scan a suffix and prefix to form the best crossing interval, then choose among the three results.
  • Kadane: the best interval ending here either extends the previous interval or starts at this element.

The answer must contain at least one element. An all-negative input therefore returns its largest element, not an empty interval with sum zero.
