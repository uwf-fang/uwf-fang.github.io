ProLog Programming Environment
------------------------------
+ Online ProLog Compiler

  * Official SWI-Prolog https://swish.swi-prolog.org/
  * Goto https://rextester.com/ and choose Prolog

+ Local ProLog Compiler

  * Install SWI-Prolog

    * Linux :code:`sudo apt-get install swi-prolog`
    * Mac OS :code:`brew install swi-prolog`

  * Run SWI-Prolog :code:`swipl -s hello.pl`

  .. code-block:: bash

    $ sudo apt-get install swi-prolog
    $ swipl -s hello.pl
