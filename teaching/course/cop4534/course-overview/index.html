      • Random variables
      • Expectation
      • Events

  • Type of problems

    • Search problem (find one qualifying solution)
    • Enumeration problem (find all qualifying solutions)
    • Optimization problem (find the best solution under an objective)
    • Decision problem (answer yes or no)
    • Counting problem (report how many qualifying solutions)

    These are requested output goals, not algorithmic paradigms. A paradigm is chosen based on the structure of the problem and the required output; no paradigm is limited to only one goal. Enumerating all solutions can answer search, decision, counting, and optimization questions, but may do more work than a direct algorithm.
