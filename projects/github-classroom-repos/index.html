GitHub Classroom Repos

Check and maintain shared files across local classroom repositories.

GitHub repository ↗

GitHub Classroom Repos provides the classroom-repos Python command-line tool for maintaining a collection of cloned programming-project repositories. A YAML configuration identifies shared files, required content, templates, and paths to synchronize between starter and solution repositories.

The tool can check README sections, build targets, test files, and other configured requirements across the collection. Pair commands compare starter repositories with their corresponding solution repositories and use marker files to track configured synchronization paths.

Batch operations report Git status, run commands across selected repositories, and clean common generated files. Update operations default to a dry run and require --apply to write changes.

After installation, a typical first check from the directory containing the repositories is

classroom-repos init
classroom-repos check
classroom-repos pair-check
classroom-repos git-status

The repository explains template-based updates, pair synchronization, repository selection, and batch commands. Python 3.10 or newer is required. The project uses the MIT license. Source, installation, and usage · MIT license
