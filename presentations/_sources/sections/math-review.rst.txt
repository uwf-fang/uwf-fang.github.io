Exponents
=========
+ Definition: An exponent is a way of expressing repeated multiplication.
+ Example: :math:`2^3 = 2 \times 2 \times 2 = 8`
+ Formula: :math:`a^n = \underbrace{a \times a \times a \times \ldots \times
  a}_{n \text{ times}}`
+ Properties

  * **Product Rule:** :math:`a^{m+n} = a^m \times a^n`
  * **Quotient Rule:** :math:`a^{m-n} = \frac{a^m}{a^n}`
  * **Power Rule:** :math:`(a^m)^n = a^{m \cdot n}`
  * **Fractional Exponent Rule:** :math:`a^{\frac{m}{n}} = \sqrt[n]{a^m}`
  * **Negative Exponent Rule:** :math:`a^{-n} = \frac{1}{a^n}`
  * **Zero Exponent Rule:** :math:`a^0 = 1, a \neq 0`

Logarithms
==========
+ Definition: The logarithm of a number is the exponent to which another fixed
  value, the base, must be raised to produce that number.
+ Example: :math:`\log_2 8 = 3` because :math:`2^3 = 8`
+ Formula: :math:`\log_b x = y` if and only if :math:`b^y = x`
+ Properties

  * **Logarithmic Identity:** :math:`\log_b b^x = x`
  * **Exponential Identity:** :math:`b^{\log_b x} = x`
  * **Product Rule:** :math:`\log_b xy = \log_b x + \log_b y`
  * **Quotient Rule:** :math:`\log_b \frac{x}{y}\  = \log_b x - \log_b y`
  * **Power Rule:** :math:`\log_b x^n  = n \cdot \log_b x`

Series
======
+ Definition: A series in mathematics is the sum of terms in a sequence.
+ Applications: algorithm analysis in computer science
+ Arithmetic series

  * Example: :math:`1 + 2 + 3 + ... + n = n(n+1)/2`
  * Formula: :math:`S_n = \frac{n}{2} \cdot (2a + (n-1)d)`
  * where:

    - :math:`n` is the number of terms,
    - :math:`a` is the first term, and
    - :math:`d` is the common difference between terms.

+ Geometric series

  * Example: :math:`1 + 2 + 4 + 8 + ... + 2^n = 2^{n+1} - 1`
  * Formula: :math:`S_n = \frac{a \cdot (1 - r^n)}{1 - r}`
  * where:

    - :math:`a` is the first term,
    - :math:`r` is the common ratio between terms, and
    - :math:`n` is the number of terms

Modular Arithmetic
==================
+ Definition: In mathematics, modular arithmetic is a system of arithmetic for
  integers, where numbers "wrap around" upon reaching a certain value—the
  modulus (plural moduli).
+ A.k.a remainder
+ Example: :math:`13 \equiv 1 \pmod{6}` because :math:`7 = 1 + 6 \cdot 2`
+ Formula: :math:`a \equiv b \pmod{n}` if and only if :math:`n | (a - b)`
+ Applications: array indexing, hash functions, pseudorandom number generators,
  etc.

Proof Methods
=============
+ Direct Proof

  :math:`A \Rightarrow B \quad \text{by assuming} \quad A \quad \text{and demonstrating} \quad B.`

+ Proof by Contradiction

  :math:`\text{Proof by contradiction assumes} \quad \neg A \quad \text{and derives a contradiction, implying} \quad A.`

+ Proof by Induction

  :math:`\text{Proof by induction involves base case} \quad (n = 1) \quad \text{and inductive step} \quad (k \Rightarrow k+1)`

  :math:`\text{to prove statement for all} \quad n.`

+ Proof by Contrapositive

  :math:`\text{Proof by contrapositive shows} \quad A \Rightarrow B \quad \text{by proving} \quad \neg B \Rightarrow \neg A, \quad \text{its logical equivalent.}`
