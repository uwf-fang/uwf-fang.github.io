COP 3530 Data Structure and Algorithm Design

Textbook and slide companion

Use these outlines and selected explanations alongside the assigned textbook and classroom slides. Short chapter pages organize the topics and link to reusable guides; they do not repeat every detail taught in class.

How to use these materials →

This course is the first of a two-course sequence on algorithms and data structures. It is designed to provide students with a solid foundation in the design, analysis, and implementation of algorithms and data structures.

Students are expected to have a good understanding of the C++ programming language and basic knowledge of data structures and algorithms before starting this course.

Prerequisite Class

  • COP3014 Algorithm and Program Design
